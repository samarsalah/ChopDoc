# Sample documents

| File | Purpose |
|------|---------|
| `text-sample.pdf` | Single-page PDF with extractable text → should **Complete** |
| `multipage-text-sample.pdf` | Multi-page text PDF → use a **low MB limit** (e.g. 0.01) to demo splitting |
| `scanned-no-text-sample.pdf` | Valid PDF with **no extractable text layer** → should **Fail** as scanned |

These files are generated by `backend/tools/GenerateSamples`.

> The assessment asks for text-based and image-only/scanned samples. Our scanned fixture targets the same business rule the converter enforces: **no extractable text layer** (rule-based conversion cannot proceed without OCR).
